## Title
Common Ground — an AI mediator that plans a night out everyone loves (Qloo Agentic Hackathon)

## Description
Two people, two different tastes, one great night. Common Ground is an agent that reads each person's taste graph through the Qloo API, finds the ground they actually share, and plans a film, a series, a soundtrack, a read and a place in Lagos, with a per-person affinity score for every pick, so nobody gets dragged along.

Live demo: https://common-ground-sama-5806.vercel.app
Source code: https://github.com/demir-sama/common-ground

Built for the Qloo Agentic Hackathon. Built with the Qloo API.
