# Demo video script — "Common Ground" (target 2:30, hard cap 3:00)

**Before recording:** `npm start` with the real `QLOO_API_KEY` in `.env` (badge should read **● Live Qloo data**). 1080p, browser zoom 100–110 %, hide bookmarks. Clear the page, close other tabs. Optional music bed under voice-over, ducked. Cut dead air while the agent trace runs (or let it play at 1.3×).

| Time | On screen | Voice-over |
|---|---|---|
| **0:00–0:15** Hook | Hero with the aurora; slow push-in on the headline. | "Every group chat has the same fight: *what are we watching tonight?* Everyone loves different things, so someone always compromises. Common Ground is an agent that finds the plan nobody has to compromise on — powered by Qloo's Taste AI." |
| **0:15–0:40** Setup | Click the **Date night** preset (or type a favourite in each card: autocomplete from Qloo `/search`). Show two person cards filling in with real titles/artists. Type a city (e.g. Lagos), toggle categories. | "Each person adds a few things they love. Those are live Qloo searches — so these are real Qloo entities, not strings. I'll add a city, and pick the categories: film, series, music, books and places." |
| **0:40–1:10** The agent | Press **Find our common ground**. Trace panel streams steps; point at "profile Maya → profile Jonas → overlap → discover film → …". | "Now the agent works, and you can watch it. It asks Qloo for each person's taste profile — the tags behind what they love. Then it asks Qloo what the *combined* taste points to, and — this is the key part — asks again, per person, how strongly each one connects with every candidate. No LLM guesses a single title; every pick comes from Qloo." |
| **1:10–1:35** Verdict | Venn animates, ring counts up, shared chips light up, then the personal chips. | "First the verdict: these two overlap 31 %, and the sweet spot is atmospheric, melancholic and cinematic. Shared tags in the middle; what makes each of them *them* on the outside." |
| **1:35–2:10** The plan | Scroll the plan cards. Hover one: per-person affinity bars. Read one "why" aloud ("Bridges Maya's … and Jonas's …"). Switch a domain tab to show alternates. | "Here's tonight's plan — one pick per category. The score is a least-misery harmony: a pick one person hates can't win on the other's enthusiasm. The bars show each person's own Qloo affinity. And the *why* is traced back to what they told us — this film bridges Maya's Blade Runner and Jonas's Amélie. Want a different one? Alternates are a tab away." |
| **2:10–2:30** Constellation + close | Scroll to "Where everyone lands": orbs sit between the two people. Click **Copy plan**. End card: logo, repo URL, "Built with the Qloo API". | "This map shows where every pick lands: close to a person means they love it more; dead centre means they both do. Copy the plan, send it to the group chat, done. Common Ground — taste is the one thing everybody has, and now it finally has a mediator." |

**Optional 15 s add-on (if time):** change the city to Tokyo and re-run to show place picks changing; or add a third person and show the triangle layout.

**Checklist:** badge says Live (not Mock) • no secrets visible (`.env` not on screen) • mention Qloo by name at least twice • show the agent trace • end on the repo URL.
